# Give Me Some Credit — Credit Default Risk Model + Dashboard

A Python rebuild of the **top-1 Kaggle** *"Give Me Some Credit"* solution
(originally written in R), packaged as a training notebook plus an
interactive Streamlit dashboard for scoring applicants.

The competition asks: given an applicant's credit history and finances,
what is the probability they experience serious financial distress
(90+ days delinquent) within the next two years?

## The modeling approach

Ported faithfully from the original R notebook:

1. **Clean**: fix the known `age == 0` outlier by replacing it with the
   training-set mean age.
2. **Feature engineering**: starting from the 10 raw columns plus 2 manual
   features (`TotalPastDue`, `DebtRatio1000`), generate:
   - per-column transforms: subtract mean, divide by mean, log, square
   - every pairwise combination of the 12 base variables: multiply,
     subtract, divide, add

   This expands 12 base variables into **~324 engineered features**.
   LightGBM handles missing values natively, so nothing is imputed.
3. **Stage 1 model**: train a LightGBM model on all ~324 features purely
   to rank feature importance (gain).
4. **Stage 2 model**: keep the **top 100 features** and retrain a
   better-tuned LightGBM model (bagging, stronger regularization) — this
   is the model that ships to the dashboard.
5. **Evaluation**: since the Kaggle `cs-test.csv` has no labels, a
   stratified 15% validation split is carved out of the training data for
   an honest ROC-AUC read. Result: **≈0.87 validation AUC**, in line with
   the original notebook's reported leaderboard performance.

## How to run

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

(Python 3.10+ recommended.)

### 2. (Optional) Retrain the model

The notebook has already been executed and its outputs (charts, metrics)
are saved inline, and the trained model is already saved under `model/`.
You only need to rerun it if you want to reproduce, retrain, or modify the
pipeline:

```bash
jupyter notebook give_me_some_credit_lgbm.ipynb
# or, to re-run headlessly:
jupyter nbconvert --to notebook --execute --inplace give_me_some_credit_lgbm.ipynb
```

This regenerates:
- `model/lgbm_model.txt`, `model/feature_stats.json`, `model/metrics.json`
- `outputs/*.png` and `outputs/submission.csv`

### 3. Launch the dashboard

```bash
streamlit run app.py
```

Then open the printed local URL (typically `http://localhost:8501`).

## Dashboard pages

- **Overview** — dataset summary, class balance, feature distributions,
  default rate by age group.
- **Score an Applicant** — enter one applicant's details manually and get
  a default probability with a risk gauge.
- **Batch Scoring** — upload a CSV (same raw columns as `cs-training.csv`)
  or use the bundled `cs-test.csv`, score every row, preview and download
  results as CSV.
- **Model Insights** — validation AUC, ROC curve, and feature importance
  for the final model.

## Notes

- `src/feature_engineering.py` is imported by **both** the notebook and
  the Streamlit app, so a record scored in the dashboard goes through
  exactly the same transforms (with the same training-set means) as the
  data the model was trained on.
- The model predicts a **probability**, not a hard yes/no. The dashboard's
  risk gauge uses simple illustrative bands (low / elevated / high) — any
  real deployment should pick a decision threshold based on business cost
  of false positives vs. false negatives.
- This is a portfolio / educational rebuild of a Kaggle competition
  solution, not a production credit-underwriting system.
